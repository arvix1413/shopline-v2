MERCHANT GUIDE

7-11 超商取貨／貨到付款
開通說明

本說明協助您啟用「7-11 取貨」與「7-11 貨到付款」。請先至綠界完成物流申請，再由 ARVIX 協助串接至您的商店。完成後，客人即可用地圖選門市，您也可取得寄件代碼至超商列印寄件單。

綠界相關連結（請先保留）

綠界賣家註冊／登入 綠界官網 綠界：如何申請物流

賣家後台登入／註冊：https://vendor.ecpay.com.tw/User/LogOn_Step1

綠界官網：https://www.ecpay.com.tw/

官方說明（申請物流）：https://support.ecpay.com.tw/26036/

依綠界規定，申請物流時須一併申請金流。物流手續費與貨到付款代收款皆透過綠界帳戶處理。

啟用後的使用方式

  • 客人於結帳頁開啟 7-11 電子地圖，選擇取貨門市（台灣出貨商店可用；與客人介面語系無關）
  • 貨到付款：下單成功後，您可於「訂單與寄件」查看寄件代碼
  • 信用卡取貨：客人付款成功後，系統才會產生寄件代碼（亦可於「訂單與寄件」手動產生）
  • 若為 C2C 交貨便（UNIMARTC2C）：請至 7-11 → ibon → 交貨便 → 輸入寄件代碼 → 列印寄件單後寄出
  • 若為 B2C 大宗（UNIMART）：出貨方式依綠界／大智通流程（通常非上述 ibon 交貨便流程），請以綠界後台說明為準
尚未完成串接前：結帳頁無法使用官方電子地圖，亦無法產生寄件代碼（僅能手填門市文字）。宅配與信用卡付款不受影響。

開通流程

  1. 1
    至綠界註冊／登入，並申請 7-11 物流

    請先開啟綠界賣家頁面：

    開啟綠界賣家註冊／登入 閱讀綠界申請說明
    • 新賣家：依綠界新手申請流程註冊，並同時申請「金流」與「物流」（綠界規定申請物流須一併申請金流）。
    • 一般賣家（已有帳號）：登入後至「廠商專區 → 驗證／服務」自行加開物流。
    • 特約賣家：請聯繫您的綠界銷售顧問協助加開服務。
    • 多數店家建議選擇 C2C 門市寄／取件（介接代號 UNIMARTC2C）。出貨量大再評估 B2C 大宗（UNIMART）。

    審核通過後，請至綠界後台「系統開發管理 → 系統介接設定」取得商店代號（MerchantID）、HashKey、HashIV。一般店家申請通過後為正式環境；測試環境僅適用綠界提供之測試帳號，請勿與正式金鑰混用。

  2. 2
    提供資料，請 ARVIX 協助串接

    請來信並提供以下資訊：

    • 商店名稱、商店網址（slug）
    • 登入用 Email
    • 綠界 MerchantID（商店代號）
    • 環境：正式（一般店家）／測試（僅限綠界測試帳號）
    • 需求項目：超商取貨、貨到付款（可同時申請）
    • 物流類型：C2C（UNIMARTC2C）或 B2C（UNIMART）

    為保護帳號安全，請勿於一般郵件直接傳送完整 HashKey／HashIV；我們將另提供安全傳送方式。

    來信申請串接

    客服信箱：arvix1413@gmail.com

  3. 3
    串接完成後即可使用
    • 客人：於結帳選擇 7-11 → 依付款方式選擇對應地圖（刷卡取貨／貨到付款）→ 選門市後下單（台灣出貨商店可用；與介面語系無關）
    • 店家：我的商店 → 訂單與寄件 → 查看或產生寄件代碼
    • C2C：至 7-11 ibon 輸入代碼列印寄件單；B2C：依綠界大宗出貨流程處理

取貨方式說明

項目 說明
信用卡＋7-11 取貨 請點「刷卡取貨：開啟地圖選門市」（非代收）。客人先刷卡；付款成功後才會產生寄件代碼。
7-11 貨到付款 請點「貨到付款：開啟地圖選門市」（代收）。客人取件時付款；貨款由綠界／超商代收至您的綠界帳戶。
宅配 無需申請 7-11 綠界物流，請依您慣用的宅配流程出貨。
提醒：選店時的「是否代收」須與結帳付款方式一致，否則無法建立物流單。

常見問題

為什麼需要自行向綠界申請？

7-11 取貨與貨到付款須使用店家自己的綠界賣家／物流帳號。ARVIX 可協助將帳號串接至您的商店，但無法代為向綠界申請，亦不會經手物流手續費或貨到付款代收款（該等款項走綠界帳戶）。

金鑰要去哪裡找？

登入綠界賣家後台 →「系統開發管理」→「系統介接設定」，即可查看商店代號（MerchantID）、HashKey、HashIV。

可以自行於後台填寫金鑰嗎？

可以（路徑：我的商店 → 收款／物流）。建議仍通知客服確認環境與物流類型（C2C／B2C），以免出現可選店但無法產生寄件代碼的情況。

非台灣出貨商店為什麼沒有 7-11 選項？

7-11 僅提供給「台灣出貨」商店。非台灣出貨商店目前僅提供宅配與信用卡付款。是否顯示與客人使用的語系、所在地無關。

大約需要多久？

綠界審核時程依綠界為準。核准並提供 MerchantID 後，請來信，我們會依序協助完成設定。

## ❌ 需要修复的问题

### 1. 选择器精确性问题
**问题**: 多个测试因为 `getByText('SHOPLINE')` 匹配到多个元素而失败
**影响**: 首页测试、用户流程测试
**解决方案**: 使用更精确的选择器，如 `page.locator('header').getByText('SHOPLINE')`

### 2. API 错误处理
**问题**: 单个商品 API 返回 500 错误而不是预期的 200 或 404
**影响**: API 集成测试
**解决方案**: 检查后端 API 的错误处理逻辑

### 3. 表格元素选择
**问题**: 管理后台表格元素选择器不够精确
**影响**: 管理后台测试
**解决方案**: 使用 `getByRole('columnheader')` 等更精确的选择器

### 4. CORS 测试方法
**问题**: Playwright 的 request 对象没有 options 方法
**影响**: CORS 测试
**解决方案**: 使用不同的方法测试 CORS 支持
